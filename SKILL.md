## Core tokens (all surfaces)

**Typography**
- Display (clock, wordmark, splash, hero numerals): **Doto** 900, round dots (variable axis `ROND=100`).
- Text and titles: **Geist** 400 / 600.
- Metadata, counters, index labels (`01 // SECTION`), status: **Geist Mono** 400 / 500, tabular numbers (`tnum`), uppercase, letter-spacing ~0.08em.
- Web: Google Fonts. Android: static TTF instances in `res/font` (cut variable fonts with `fonttools varLib.instancer`, e.g. `Doto wght=900 ROND=100`, `Geist wght=400/600`, `GeistMono wght=400/500`).

**Palette**

| --- | --- | --- | --- |
| bg | `#0E0E0E` | `#F3F2EF` | `#000000` |
| surface | `#151515` | `#FBFAF8` | `#0A0A0A` |
| line | `#262626` | `#D9D6D0` | `#1F1F1F` |
| line-strong | `#3A3A3A` | `#BDB9B1` | `#333333` |
| text | `#ECEBE8` | `#141413` | `#ECEBE8` |
| muted | `#9A968F` | `#5F5B55` | `#8F8B84` |

| dot (grid) | `#2B2B2B` | `#CFCBC4` | `#1C1C1C` |

**Section hue wheel** — each section/row/category gets `h = 35 + i * 360 / n`; colour =
`oklch(0.76 0.12 h)` on dark, `oklch(0.48 0.14 h)` on light (≥ 4.5:1). Used for swatch dots,
index labels, focused row titles, splash progress segments. Never for body text.

**Signature elements**
- Hairlines (1px / 1dp) instead of shadows and fills; radius small (6–8, cards 8).
- Radial dot grid background: 1.2px dots every 16px (`dot` token).
- Orange LED dot as identity mark (status bar, icons, selected state instead of ✓).
- Index labels `01 // TITLE` in mono; counts in tabular mono.
- Motion: `cubic-bezier(.16, 1, .3, 1)` (ease-out-expo), wipe-in for titles, background
  expanding from the left on focused/hovered rows, dot-matrix boot splash once per session.
- Respect reduced motion (web `prefers-reduced-motion`, Android `ValueAnimator.areAnimatorsEnabled()`).

## Workflow

1. Identify surface(s) → read the matching reference(s) and `references/taste.md`.
2. Put tokens in ONE owner (CSS `:root` vars / Kotlin `ThemeManager` preset) — no hard-coded colours elsewhere; light theme must work by swapping tokens only.
3. Reuse the script/template instead of re-deriving; generated assets carry a "generated by" header.
4. Verify on the real target (browser / device screenshot), both themes, contrast ≥ 4.5:1, focus visible from 3 m on TV.
5. Show the user a before/after (screenshot or contact sheet) before declaring a visual change done.
